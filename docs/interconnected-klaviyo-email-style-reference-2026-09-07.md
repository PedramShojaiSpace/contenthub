# Interconnected Kajabi Email Style Reference

## Source Pages Reviewed

1. `https://theacademy.theurbanmonk.com/ic-interconnected-free-screening-Meta`
2. `https://theacademy.theurbanmonk.com/episode-view-page-eg-ep-1-SP26`

## Visual Signals to Carry Into Email

The screening page uses a near-black navy/blue-green visual field, white display typography, a restrained cyan-teal action color, clean white form fields, and one dark form container. The episode-view page reinforces the white wordmark, dark cinematic framing, muted natural imagery, and cyan/teal action treatment.

The email should not recreate the textured/video background, form panel, or page complexity. The deliverability-safe translation is a white email canvas with one dark-navy header band, charcoal body copy, a single cyan-teal CTA, thin blue-green dividers, and an optional lightweight Interconnected wordmark only if the team has a hosted approved image with meaningful alt text.

## Content Boundary

The episode page contains named viewer statements. These are not part of the email style recommendation and must not be copied into a Klaviyo template without separately verified, approved testimonial provenance.

## Recommended Klaviyo Template Treatment

Use a **600 px centered email** with a white content canvas. Give the header a dark blue-green band with a small white Interconnected wordmark or plain-text `INTERCONNECTED` title. Keep body copy dark and spacious. Use the cyan action color once, for the primary button. This preserves the experience of the two pages without turning the email into a graphic-heavy landing page.

| Element | Email-safe value | Application |
|---|---|---|
| Outer background | `#F3F6F5` | Light warm-gray page surround; no background image. |
| Content canvas | `#FFFFFF` | White reading surface; 20–28 px side padding. |
| Header band | `#062B38` | 16–22 px of vertical padding; white title/wordmark only. |
| Main headline | `#062B38` | 26–30 px desktop / 24 px mobile; use a clean sans-serif. |
| Body text | `#233840` | 16–17 px; 1.5–1.6 line height. |
| Primary CTA | `#087E9D` with `#FFFFFF` text | Solid rectangular button, 16 px bold label, 12–16 px radius maximum. |
| Text links | `#056C88` | Underlined; do not rely on color alone. |
| Divider / quiet accent | `#CFE3E5` | One-pixel rule or a small section label; do not add multiple colored boxes. |

### Layout Order

1. Dark header band with `INTERCONNECTED` (plain text is acceptable and generally lighter than a logo image).
2. One concise white-space-led headline and opening paragraph.
3. Optional single video still or episode image only when it adds context; add meaningful alt text and keep the email useful if images are blocked.
4. One primary cyan-teal CTA.
5. Short educational body and a standard legal/footer block in dark gray on white.

### Manual Klaviyo Settings

Set the email canvas/background to `#F3F6F5`, content block to white, header block to `#062B38`, headline to `#062B38`, ordinary copy to `#233840`, and the sole main button to `#087E9D` with white text. Use a 600 px content width, 16 px minimum body text, and at least 44 px button height. Remove gradients, background video, decorative puzzle imagery, floating overlays, external web fonts, JavaScript, and secondary competing buttons.

### Pre-Send Check

Confirm that the correct destination URL is present, UTM/source key matches the flow and message version, the unsubscribe/footer content remains intact, preview text has been added, and the email renders coherently with images disabled. This style pass does not change any CTA, consent path, SMS rule, or flow logic.

## How this changes the prior reading

The prior launch-window snapshot showed Kajabi ahead at 0.90 booked ROAS versus 0.39 for Klaviyo/Shopify. The rolling window now isolates a newer cohort, and that newer cohort is producing the opposite result. This is consistent with the owner’s observation that the Klaviyo path is beginning to pull ahead.

It does **not** prove that the entire original cohort has reversed. A rolling 24-hour report answers a different question: how are the newest leads converting so far? The launch-window report remains the appropriate cumulative baseline, while this report is the appropriate short-term momentum view.

## Recommended Test Sequence

The cleanest order is to test one high-intent change at a time. First test the price-aware hero CTA, then the package-expectation line, then the pricing-block inclusion summary. Preserve a control version and retain the existing BixGrow parameter in every test URL and native cart link. The evaluation should use affiliate-attributed Shopify orders as the conversion source, not synthetic events or unsourced platform counts.

## Elements Not Recommended for Immediate Testing

It should not use disease claims, diagnose visitors, or convert the oral-microbiome context into medical certainty. It should also not introduce fabricated social proof, urgency counters, or misleading availability claims.
